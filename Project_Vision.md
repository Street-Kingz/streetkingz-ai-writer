# Project Vision - Street Kingz AI Ecommerce Assistant

## Purpose

The purpose of this project is not to build another AI article writer.

The goal is to build an AI-powered ecommerce assistant that removes as much repetitive manual work as possible whilst producing commercially valuable output.

The system should make better decisions than a human can make manually in the same amount of time.

If a task can be automated reliably, it should be.

The user should never need to become a prompt engineer.


---

# Core Principles

## 1. Workflow Driven

The user should never write prompts.

Instead they choose what they want to achieve.

Examples:

- Create SEO Article
- Improve Existing Article
- Optimise Product Page
- Find Content Opportunities
- Build Supporting Articles
- Analyse Competitors
- Find Internal Linking Opportunities
- Generate Video Ideas

Each workflow contains its own hidden AI prompts.


---

## 2. Product First

Everything starts with the product.

Rather than typing a keyword or topic, the user supplies a product URL.

Example:

https://streetkingz.co.uk/product/heavy-duty-drying-towel-1200gsm/

The system then understands:

- Product
- Category
- Specifications
- Features
- Benefits
- FAQs
- How to use
- Common objections
- Related products
- Internal links
- Customer language

The AI should never have to guess what the product is.


---

## 3. Research Before Writing

The system should never immediately generate content.

Instead it should understand the product before deciding what content should exist.

Writing is the final stage.

Not the first.


---

## 4. Decisions Before Content

The system should ask:

"Is this actually worth writing?"

Not every product deserves a standalone article.

Sometimes a broader guide will generate significantly more traffic and sales.

The AI should recommend the highest value opportunity.

It should never blindly follow the input.


---

## 5. Commercial First

Traffic alone is not success.

Every workflow should ultimately support one or more of the following:

- Sell products
- Increase authority
- Increase conversions
- Improve user experience
- Reduce manual work
- Increase long-term organic visibility

---

# Product Understanding

The first stage should gather factual information from multiple sources.

Priority order:

1. WooCommerce product data

2. Rendered product page

3. Product FAQs

4. Existing internal links

5. Brand catalogue

This becomes the factual foundation for every workflow.


---

# Research Layer

The AI extracts:

- what the product is
- who it is for
- who it is not for
- problems it solves
- alternative names
- customer language
- likely search intent
- related questions

These become research seeds.

Research should never rely purely on the product title.


---

# External Research

Research APIs provide:

- keyword opportunities
- search volumes
- keyword difficulty
- SERP features
- People Also Ask
- related searches
- competitor pages

The AI uses this information to decide whether a topic is commercially worthwhile.


---

# Decision Layer

The AI chooses the highest value opportunity.

Possible outcomes:

Create a cornerstone guide.

Create a supporting article.

Improve an existing article instead.

Improve the product page instead.

Do nothing because there is insufficient opportunity.

A valid outcome is deciding not to create content.


---

# Content Brief

Once an opportunity has been selected, the system creates a structured brief.

Example:

Target keyword

Search intent

Target reader

Questions to answer

Competitors

Internal links

Products to feature

Call to action

Images required

Target length

Only once this brief exists should AI begin writing.


---

# Content Generation

Generation follows predefined templates.

The AI does not invent structure.

Templates control:

- page layout
- heading hierarchy
- CTA placement
- featured products
- FAQs
- internal linking
- schema
- image placeholders

This ensures consistency across every page.


---

# Human Review

The AI should never publish automatically.

The user reviews:

- factual accuracy
- tone
- brand alignment
- product recommendations
- commercial intent

Only then is the content published.

# Success Criteria

The project is successful if it allows a business owner to perform work that would normally take hours in only a few minutes.

The goal is not to replace human judgement.

The goal is to automate the repetitive work whilst improving the quality of the final output.


---

# Non-Goals

This project is not trying to:

- Replace human decision making
- Publish content without review
- Produce AI spam
- Chase search volume at the expense of relevance
- Generate articles simply because a keyword exists

Every piece of content should exist because it supports the business.

Quality always takes priority over quantity.
