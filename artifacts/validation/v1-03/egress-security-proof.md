# V1-03 egress foundation

The 36-test focused suite proves HTTPS-only exact identity origins, DNS-to-socket pinning, original-host SNI and Host semantics, enabled certificate verification, GET-only construction, no method override, bounded same-host/base-path redirects, `_fields` preservation, private/host-changing redirect rejection, socket inactivity and absolute wall-clock deadlines, response-size limits, strict JSON handling, safe provider states, and suppression of raw socket details. Basic Auth is sent only as an Authorization header.
