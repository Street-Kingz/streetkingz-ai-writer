# V1-03 egress foundation

The 27-test focused suite proves HTTPS-only public destinations, DNS-to-socket pinning, original-host SNI and Host semantics, enabled certificate verification, GET-only construction, no method override, bounded same-host/base-path redirects, private/host-changing redirect rejection, timeout and response-size limits, strict JSON handling, safe 401/403/429/unavailable states, and suppression of raw socket details. Basic Auth is sent only as an Authorization header.
