# V1-03 egress foundation

The 67-test focused suite proves HTTPS-only exact identity origins, DNS-to-socket pinning, original-host SNI and Host semantics, enabled certificate verification, GET-only construction, no method override, bounded same-host/base-path redirects, `_fields` preservation, private/host-changing redirect rejection, initial and redirect late-DNS cancellation, auth-init DNS deadlines, response-size limits, strict JSON handling, malformed redirect sanitisation, exact retryable provider states, and suppression of raw socket details. Basic Auth is sent only as an Authorization header. The retained SSRF matrix rejects private, loopback, link-local, metadata, multicast, reserved/documentation and IPv4-mapped private IPv6 answers while accepting public IPv4 and globally routable IPv6.
