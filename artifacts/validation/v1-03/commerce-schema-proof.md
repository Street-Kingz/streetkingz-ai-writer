# V1-03 foundation schema proof

Real local Supabase operations passed all 42 named integration behaviours. Composite foreign keys enforce Account → Business → Woo Connection → Store ownership and same-Store Generation attribution. Existing Store identity cannot be rebound: same-canonical reauthorization refreshes bounded identity fields while a different canonical base fails with `WOO_STORE_REBIND_DENIED` and preserves the current Generation. Authenticated roles are SELECT-only and see evidence only when its complete snapshot Generation is current. Service-role Store/auth-attempt writes are also denied; fixed-purpose lifecycle and promotion RPCs remain available.
