# V1-03 foundation limitations

This checkpoint intentionally does not claim V1-03 completion. Public Express callback/return route wiring, live-provider acceptance, and final commercial aggregation remain outside the foundation. Host-changing redirects, including `www.` changes, remain rejected because the approved contract defines no safe pre-auth canonical-host equivalence and Basic credentials must not cross hosts. Tests use synthetic credentials only; no live credential or provider payload is persisted in repository evidence.
